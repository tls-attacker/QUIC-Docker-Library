## Requiered Server Parameters

```bash
[CERTIFICATE] [PRIVATE_KEY] [PORT] 
```

## Requiered Client Parameters

```bash
[PORT]
```

## Note

- The client always connects to `localhost` and does not verify the server certificate; it has no option to change either.

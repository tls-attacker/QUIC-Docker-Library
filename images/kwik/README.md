# kwik

## Source

[https://github.com/ptrd/kwik](https://github.com/ptrd/kwik)

## Requiered Server Parameters

```bash
[CERTIFICATE] [PRIVATE_KEY] [PORT] 
```

## Requiered Client Parameters

```bash
[PORT]
```

## Note

- The client always connects to `localhost`.
- The client does not verify the server certificate and has no option to enable verification.

# kwik

## Source:

[https://github.com/ptrd/kwik](https://github.com/ptrd/kwik)

## Supported Versions:

0.8.9, 0.8.10

## Building the Docker Image
```
docker build --build-arg VERSION=0.8.10 --no-cache -t kwik-server:0.8.10 .
```

## Starting the Docker Container
```
docker run kwik-server:0.8.10
```
